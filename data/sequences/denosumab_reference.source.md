# Denosumab reference sequence provenance

- Heavy chain: 448 amino acids.
- Light chain: 215 amino acids.
- Sequence identifiers used by the analysis: `DENOSUMAB_HC` and `DENOSUMAB_LC`.
- Primary sequence source: US Patent 9,695,244, SEQ ID NO:1 (heavy chain) and SEQ ID NO:2 (light chain), describing sequences determined from Prolia/denosumab.
- Independent length and molecule-type check: Japan NIHS Biologicals denosumab monograph (human IgG2; 448-aa heavy chain and 215-aa light chain).

Sources:

- https://patents.justia.com/patent/9695244
- https://www.nihs.go.jp/dbcb/Biologicals/denosumab.html

The FASTA contains the mature antibody chains without signal peptides. Sequence length and amino-acid alphabet were validated before analysis.
