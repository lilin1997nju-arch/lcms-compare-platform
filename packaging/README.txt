LC-MS Department Platform

Install:
  Run LCMS_Department_Platform_Installer.exe.

Default install directory:
  %LOCALAPPDATA%\LCMS Department Platform

The installer includes its own Python runtime and ThermoRawFileParser. No
separate Python installation is required.

Start:
  Use the desktop shortcut or Start-LCMS-Platform.cmd.

Stop:
  Run Stop-LCMS-Platform.cmd.

The platform stores uploaded task data under:
  app\lcms_department_platform\jobs

The MCP endpoint is available locally at:
  http://127.0.0.1:8770/mcp
