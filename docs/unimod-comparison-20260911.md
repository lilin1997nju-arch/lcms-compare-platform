# QL2519：Unimod 二阶段搜索对照结果

日期：2026-09-11。最终规则，不采用首次试运行的候选统计。

## 结论

本数据集的新增搜索阶段约 2 秒；独立重复三次为 2.283、1.843、1.841 秒，
中位数 1.843 秒，三次候选与 A/B 中的候选完全一致。
保留原有分析流程后，为 67 个 Feature 提供了 261 条探索性候选。
这些是跨样本、不同骨架及修饰的候选记录，不是 261 个新增可靠鉴定。

## 完整 MS2 流程 A/B

| 指标 | 关闭新增搜索 | 开启新增搜索 |
| --- | ---: | ---: |
| MS2 进程总耗时 | 181.621 秒 | 162.562 秒 |
| 其中 Unimod 新增阶段 | 无 | 2.001 秒 |
| 原有报告接受 PSM 数 | 6,371 | 6,371 |
| 新增探索候选涉及 Feature | 0 | 67 |
| 新增探索候选记录 | 0 | 261 |

后一次总耗时较短，不能解释为新增搜索带来了提速。两次按基线→增强顺序运行，
缓存、CPU 状态和系统负载会影响原有阶段，尤其序列搜索及修饰配对阶段。
能直接归因于新增搜索的工作是单独计时的第二阶段；包括写盘在内的精确净开销
还需要更多顺序交叉测试，不能用本次总耗时差推算。

不包含 RAW 转换和 MS1 分析，两次都复用同一套缓存 mzML 和相同 MS1 SQLite
的副本。本次结果不代表其他更大数据集、不同酶或不同蛋白范围的固定开销。

## 检索统计与完整性

- 离线 Unimod 原始 XML：1,560 条记录。
- 符合条件的未解释差异 Feature：276；所选样本 MS2 扫描记录：460。
- 质量差与位点兼容的骨架记录：19,389；通过快速碎片预筛：3,864。
- 每谱最多保留 12 个骨架，合计截去 2,767 个骨架记录；实际评分 6,492 个位点候选。
- 每个 Feature/样本最多展示 3 个候选，全部标记为探索性，`q_value=null`。
- 移除两个新增 Feature 字段及报告的 Unimod 搜索汇总后，整个 A/B 报告精确相等：
  `first_pass_and_quantitation_identical=true`。原有序列解释、PSM、Feature 状态、
  修饰形式配对及定量都未被改变。
- `top_n_mz=200`、`candidate_max_per_tic=200`、`top_n_peaks=0` 未改动；
  上传接口自动化测试验证了保存值。
- 72 项分析/界面代码测试及 6 项平台/MCP/上传测试通过。
- 浏览器已检查酶类型切换、最终候选选择、对应 b/y 数量及样本隔离。单文件
  离线报告已通过现有导出器生成；本轮浏览器工具不允许直接访问 file URL，
  因而直接双击打开的路径未进行浏览器实测。

## 证据限制

此处没有新增独立的 target-decoy FDR 校准，也没有实验证实每条候选。
化学衍生化、金属加合物及制样伪影可能只是同质量解释，必须核对实验条件。
最高分位点只是绘图模型，不能当成定位概率。交联试剂、虚拟碎片离子、内部
残基缺失等不适合当前模型的条目已排除；完整数据库原文仍随软件分发。
