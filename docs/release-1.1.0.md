# LCMS Desktop 1.1.0

发布日期：2026-09-11。Electron 桌面版和独立 MCP.exe 版本均为 1.1.0。

## 本次发布

- 新建任务支持酶切类型选择，保留旧任务的 Trypsin 默认行为。
- 内置完整离线 Unimod 数据库与单个新增修饰的独立探索搜索，不写入正式鉴定或定量。
- 制样条件按质量模型合并：还原状态为已充分还原／未还原／未知；烷基化为
  IAA/CAA 类／未烷基化／未知。不为 DTT、TCEP 等相同终态再增加多个选项。
- 未烷基化真正关闭固定 Cys +57.021464 Da，同时限制 CAM 探索规则；
  非还原模式只搜索不含 Cys 的线性肽，尚不支持二硫键连接肽或部分还原/烷基化。
- 生物素化、TMT、iTRAQ 采用使用过／未使用／未知三态，按明确试剂依赖过滤探索候选。
- 汇总此前桌面更新：组内一致修饰配色、Feature 编号/序列搜索、探索性 b/y 标注、
  MS/MS 样本切换、热图高度及计算优化。
- 新版卸载脚本增加数据/配置备份和恢复失败检查，失败时停止删除或后续操作；
  保留的目录可手工恢复。此修改不能追溯替换旧版已经安装的卸载器。

固定参数仍为 `top_n_mz=200`、`candidate_max_per_tic=200`、`top_n_peaks=0`。
未知制样条件沿用旧版线性还原肽和固定 CAM-Cys 假设，并显示警告；不按文件名猜测。

## 验证与交付

- 分析侧 80 项、平台/MCP 侧 7 项自动化测试通过。
- 合成谱运行真实搜索及报告流程，核对未烷基化与 CAM 模型的鉴定差异，
  检查前体/碎片/诱饵质量一致性与非还原候选限制。
- 浏览器验证新建表单选项和切换后的模型提示，无控制台错误。
- Electron/NSIS 构建通过；打包源码和数据库校验一致，MCP.exe 初始化返回 1.1.0。
- 未在用户正在运行的安装目录上执行升级；没有重算或覆盖已有任务。

安装包：`release/electron/LCMS-Desktop-1.1.0-Setup.exe`（Windows x64）。
自包含 Electron、Python、ThermoRawFileParser、Unimod 和独立 MCP.exe。
安装包未做发布者数字签名。升级前关闭程序并备份安装目录下 `data` 和
`lcms-desktop-config.json`（如存在），尤其从旧版升级时不要依赖旧卸载器的异常保护。
安装包保留在本地 `release`，不随源码推送；没有发布 GitHub Release。

详细规则与来源见 [Unimod 与制样说明](unimod-and-enzymes.md)。
